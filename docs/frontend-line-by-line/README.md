# Frontend, line by line

JumpyBrain’s frontend (`frontend/`) explained twice.

- [How the files work together — technical](tandem-technical.md)
- [How the files work together — simple](tandem-eli5.md)
- [Technical, every line](technical/)
- [Simple, every line](eli5/)

Open a file such as `technical/src/App.jsx.md`. Each block is:

```
  12 |         <App />
     | what that exact line does
```

The simple copy of the same line is in `eli5/src/App.jsx.md`.

`src/styles.css` is included. Those lines set paint (colors, layout, and which rules apply on a phone). They do not fetch data or change routes.
